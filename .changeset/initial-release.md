Initial release of the Cosmonexus package suite.

- `nova-types`: Foundational types for reactive system and prose editor
- `nova-store`: Reactive state management (signals, effects, scopes, RxJS Store)
- `nova-react`: React integration hooks for nova-store observables
- `nova-svelte`: Svelte 5 integration (store adapters, CodeEditor, RichEditor)
- `prose`: ProseMirror-based rich-text editor for novel authoring
- `cm`: CodeMirror 6 facade package
- `stellate`: High-level editor abstraction
- `design-tokens`: Vanilla-extract theme/token system
- `tsconfig`: Shared TypeScript configuration
- `nova-ui`: React component library
- `nova-ui-solid`: SolidJS component library
